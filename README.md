# Library Book Inventory System

A Java Swing desktop application for managing library books using SQLite database.

## Features

- Add Book
- Update Book
- Delete Book
- Search Book
- JTable Display
- SQLite Database Integration
- Improved Dashboard UI

## Technologies Used

- Java (JDK 21+)
- Java Swing
- SQLite
- JDBC

## Project Structure

- Dashboard.java
- AddBookForm.java
- UpdateBookForm.java
- DatabaseConnection.java
- Main.java

Database file:
